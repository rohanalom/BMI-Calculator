# BMI Calculator

A simple and stylish BMI (Body Mass Index) Calculator built using .NET MAUI. This app allows users to calculate their BMI based on their weight and height while providing gender-specific categorization.

## 📸 Screenshots
![BMI Calculator Screenshot](https://github.com/rohanalom/BMI-Calculator/blob/main/appss1.jpg)

## ✨ Features
- Smooth UI with gradient background
- Gender-specific BMI classification
- Animated result display with fade-in and scaling effects
- Fully responsive for different screen sizes
- About section with developer credits

## 🛠️ Technologies Used
- .NET MAUI
- C#
- XAML for UI design

## 🚀 Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/rohanalom/BMI-Calculator.git
   ```
2. Open the project in **Visual Studio**
3. Ensure you have the necessary dependencies installed
4. Run the app on an emulator or physical device

## 📌 Usage
1. Select gender (Male/Female)
2. Enter weight in kilograms
3. Enter height in centimeters
4. Click **Calculate BMI**
5. View your BMI result with category and color indicator
